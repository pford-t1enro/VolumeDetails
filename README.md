## Operações matemáticas

O jogador avalia o resultado de uma expressão com números sorteados, e o número de termos cresce a cada acerto. Pensei em sortear entre soma e subtração. Divisão fica de fora porque, sem escolher o divisor com cuidado, o resultado vira fração. Multiplicação também fica de fora porque a expressão pode ficar pesada demais, como um número de dois dígitos multiplicado por outro.

Exemplo com números sorteados:

```
55 + 12

(acerto)
(próxima)
77 + 2 - 14

(acerto)
(próxima)
99 - 3 - 30 + 8 

(erro)
(próxima)
55 + 22 - 44 + 17
```

Por enquanto só montei a estrutura do desafio, instalei as dependências e tal.
